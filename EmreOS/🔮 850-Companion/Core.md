## İlkeler

- Bilgi yerel Markdown olarak kalır.
- Grafik, yalnızca dosya ve wikilinklerden üretilir; token harcamaz.
- Codex yalnızca Emre soru sorduğunda seçili bağlamla çağrılır.
- Kalıcı içgörüler ilgili nota kaydedilir.
